# 코드 명확성 원칙 조회

사용자가 이 원칙을 명시적으로 요청하거나 별도로 허용한 개인 자산 조회 정책에 따라 관련성이 높은 경우에만 `knowledge.md`를 읽는다. 대상 프로젝트의 기존 언어·팀 규칙과 현재 사용자 지시를 우선한다. 이 자산은 코드 표현을 판단하며 특정 스타일 도구나 구문을 강제하지 않는다.
