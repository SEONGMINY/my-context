# 증거 기반 개선 판단 원칙 조회

사용자가 실행·사용 증거로 제품이나 개발 과정의 개선 필요성·우선순위·효과를 판단해 달라고 요청했거나, 사용자가 별도로 허용한 개인 자산 활용 정책에 따라 관련성이 높은 경우에만 `knowledge.md`를 조회한다.

이 자산은 **개선을 판단하는 참고 지식**이다. 측정 시스템 구축, 자동 개선 루프 실행, 파일 수정·배포, 다른 개인 자산의 자동 조회를 지시하거나 승인하지 않는다. 대상 프로젝트 계약과 최신 사용자 지시를 우선하며, 본문은 실제 개발 대화에서 일반화한 **후보 원칙**으로 취급한다.
