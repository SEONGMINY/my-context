# 명확한 설명과 시각화 원칙 조회

사용자가 복잡한 개념·구조·흐름·변화를 쉽게 설명하거나 도식화해 달라고 요청한 경우, 또는 별도로 허용한 개인 자산 조회 정책에서 관련성이 높은 경우에만 `knowledge.md`를 읽는다. 짧고 자명한 답변에 불필요한 시각화를 강제하지 않는다. 사용자 지시, 실제 근거, 대상 프로젝트의 제약과 지원되는 출력 형식을 우선한다. 본문은 범용 전달 방식에 관한 후보 원칙이며 특정 다이어그램 도구나 AI 제품을 요구하지 않는다.
