# 개발 판단 원칙 조회

사용자가 개인 개발 판단 원칙을 활용해 달라고 명시적으로 요청한 경우에만 `knowledge.md`에서 해당 상황에 필요한 부분을 읽는다. 이 문서는 대화에서 도출한 판단 기준의 **제안된 정리**이며 모든 문장을 사용자가 직접 선언한 것으로 취급하지 않는다. 대상 프로젝트의 계약을 우선한다.
