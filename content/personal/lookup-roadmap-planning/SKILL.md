# 단계별 구현 범위 원칙 조회

사용자가 이 판단 원칙을 활용해 달라고 요청했거나, 사용자가 별도로 허용한 개인 자산 활용 정책에 따라 현재 요청과 관련성이 높은 경우에만 `knowledge.md`를 조회한다. 현재 프로젝트의 계약과 최신 사용자 지시를 우선한다. 본문은 과거 대화에서 일반화한 **후보 원칙**이며 사용자의 원문 선언으로 간주하지 않는다.
