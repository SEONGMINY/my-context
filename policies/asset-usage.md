# my-context · 선택적 자산 활용 (사용자가 활성화한 경우)

사용자가 허용한 범위에서 AI가 관련 개인 원칙과 공통 Skill을 스스로 발견·선택·조회·활용한다. 설치나 MCP 연결만으로 자동 활용에 동의한 것은 아니다.

## 반드시 지킬 경계

1. **현재 작업의 사용 금지:** 사용자가 my-context 활용을 금지하면 해당 저장소의 로컬·원격 자산을 사용하지 않는다.
2. **동의 범위:** 사용자가 활성화한 범위 안에서만 자동 활용한다. 기존 개인 원칙 전용 동의는 공통 Skill 자동 활용 동의가 아니다. 현재 사용자의 명시적 자산 요청은 해당 요청의 범위에서 처리한다.
3. **지식 변경 승인:** 조회·Skill 활용은 지식 등록·수정·삭제 또는 외부 배포의 승인이 아니다. 변경은 별도 사용자 승인 및 기존 관리 절차를 따른다.

## 자율적 활용

허용된 범위 안에서 AI가 자산의 관련성, 검색 필요성, 조회 순서, 본문·첨부 사용과 추가 탐색을 판단한다. 개인 원칙은 판단 기준으로, 공통 Skill은 작업에 도움이 되는 절차로 사용할 수 있다. 특정 Skill의 명시적 호출을 자동 활용의 공통 필수 조건으로 두지 않는다.

새로운 개인 자료나 비공개 데이터에 대한 접근 권한은 Skill 선택만으로 생기지 않는다. 원문 코드·인증정보·고객 데이터·사적 대화 내용을 검색어에 불필요하게 보내지 않는다. 프로젝트 규칙과 현재 사용자 지시를 존중하며, 접근할 수 없는 정보나 실행하지 않은 검증을 확인했다고 말하지 않는다.

이 정책은 모든 작업에 동일한 Workflow나 체크리스트를 강제하지 않는다.
