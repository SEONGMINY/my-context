# my-context · 개발 자산 자동 참고

AI는 개발 작업에서 my-context의 관련 개인 원칙과 공통 Skill을 자율적으로 발견·선택·조회·참고할 수 있다. 별도의 ON/OFF 활성화나 Skill 이름의 명시적 호출은 요구하지 않는다. 사용 가능한 자산을 매번 전부 조회하거나 강제로 적용하는 의미는 아니다.

## 반드시 지킬 경계

1. **현재 사용자 지시 우선:** 사용자가 이번 작업에서 my-context 활용을 금지하면 로컬·원격 자산을 조회하거나 적용하지 않는다.
2. **프로젝트 계약 우선:** 해당 프로젝트의 요구사항·규칙·아키텍처 계약을 my-context의 일반 원칙보다 우선한다. 충돌하면 차이를 설명한다.
3. **읽기와 변경 분리:** 자동 참고는 지식 등록·수정·삭제, Git 반영, 운영 배포, 추가 개인 자료 접근을 승인하지 않는다. 변경은 별도 사용자 승인과 기존 관리 절차를 따른다.

## 필요한 만큼 자율적으로 참고

AI가 작업의 요구·설계·구현·검증 등 판단에 개인 원칙이나 공통 Skill이 도움이 되는지 살피고, 필요하면 사용자의 명시적 자산 호출 없이 검색한다. 검색 필요성, 조회 순서, 본문·첨부 사용 여부는 상황에 맞게 결정한다. 관련성이 낮거나 이미 유효한 맥락이 충분하면 중복 조회를 생략한다. 개인 원칙은 판단의 참고 기준으로, 공통 Skill은 필요할 때 선택하는 절차로 활용한다. 특정 Skill을 모든 개발 작업에 강제하지 않는다.

원격 검색어에는 비공개 코드 원문, 인증정보, 고객 데이터, 사적 대화 내용 등 불필요한 민감 정보를 넣지 않는다. 기존에 제공되거나 별도로 접근이 허용된 자료만 사용한다. MCP 연결·인증 또는 자산 본문 조회가 불가능하면 성공했다고 주장하지 않는다.

이 정책은 에이전트가 읽는 사용자 지침이며 파일 접근을 기술적으로 차단하는 보안 경계가 아니다. 지침 파일을 설치하거나 원격 MCP를 연결하는 것만으로 모든 호스트의 자동 적용이 보장되지는 않는다. 실제 새 세션의 행동을 따로 확인한다.
